Personal use

Personal email review.

MailBridge helps its owner review selected Gmail accounts, keep track of messages that need attention, and prepare replies for review.

The application runs on the owner's Windows computer, with an iPhone app for reviewing items. These pages explain its use and data handling. There is no public sign-up; the owner operates the installation.

What the application does

  • Reads messages from accounts the owner connects through Google authorization.
  • Uses hosted Claude analysis to suggest categories, follow-ups, and reply text.
  • Adds MailBridge labels in Gmail and tracks items the owner handles, snoozes, or marks as waiting.
  • Saves a Gmail draft only after the owner reviews and requests it. The application does not send messages or delete mail.
  • Can send a generic iPhone notification when an item needs attention.

Email content leaves the Windows computer for analysis. Message subjects, body text, and selected thread context are sent to Anthropic's hosted Claude service. Local storage encryption and a private phone connection do not make this analysis offline.

The owner must keep Claude's model-improvement setting off for this use. Provider retention and safety exceptions still apply. Read the hosted analysis disclosure before connecting an account.

Storage and phone access

MailBridge encrypts the contents of its stored database records on the Windows host. The owner manages the host, its configuration, and data removal. The phone connects through an owner-configured private HTTPS connection using Tailscale.

The privacy policy explains the data collected, provider access, storage limits, and removal controls. The terms of use describe the owner's responsibilities and the application's limitations.
